# Changelog

All notable changes to the SvelteSharp VS Code extension are documented here.

## [0.1.0] - 2026-11-24

### Added

- Initial SvelteSharp VS Code extension release.
- C# component diagnostics.
- Syntax validation.
- Semantic validation for supported C# constructs.
- Support for `.svelte.cs` sidecar files.
- Support for inline `@code` blocks.
- VS Code Problems panel integration.
- SvelteSharp compiler integration.
